### Instrucciones de ejecución:
Para comenzar clona este repositorio en una nueva carpeta con el comando:
*git clone https://github.com/julilarzabal/TPE_Ciencia_de_Datos.git*

Luego realiza los siguientes comandos en el orden indicado para crear, entrar e instalar los requerimientos en tu ambiente virtual:
1. *python3 m venv venv*
2. *source venv/bin/activate*
3. *pip install -r requirement.txt*

Por último, deberás abrir el notebook con el código fuente del trabajo. Dentro del mismo tendrás que ir ejecutando una a una las celdas, en el orden en el que se encuentran. 
Para abrir el notebook utiliza el comando *jupyterlab*
