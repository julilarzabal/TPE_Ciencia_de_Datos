### Instrucciones de ejecución:
Para comenzar clona este repositorio en una nueva carpeta con el comando:
*git clone*

Luego realiza los siguientes comandos en el orden indicado para crear, entrar e instalar los requerimientos en tu ambiente virtual:
1. *python3 m venv venv*
2. *source venv/bin/activate*
3. *pip install -r requirement.txt*

Por último, ejecuta el comando indicado a continuación para abrir el notebook con el código fuente del trabajo. 
Dentro del mismo deberás ir ejecutando una a una las celdas, en el orden en el que se encuentran. 
*jupyterlab*
